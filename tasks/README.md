# Benchmark task instances

This repository contains 8 benchmark task instances for the approved CP-08 task families.

## Task families

- T01: Complex Survey Design and Weight Interpretation (intermediate)
- T02: Survey-Weighted Predictive Modelling (advanced)
- T03: Data Leakage Detection and Prevention (advanced)
- T04: Validation Strategy Selection (intermediate)
- T05: Class Imbalance and Performance Evaluation (advanced)
- T06: External Validation and Distribution Shift (advanced)
- T07: Missing Data and Statistical Uncertainty (advanced)
- T08: Model Calibration and Interpretability (advanced)
